# Nexus Shell 2.0

**Nexus Shell** — файловый менеджер для Windows 11 в стиле самой системы: вкладки на Mica, боковая панель,
панель сведений с предпросмотром и всё привычное по Проводнику, плюс разделы, которых в Проводнике нет, —
игры, приложения, AI-центр, торренты и разбор «Загрузок».

Версия 2.0 — полная переработка: новый код на .NET 10 и Windows App SDK 2.5 (WinUI 3).
Nexus не заменяет оболочку Windows: панель задач, «Пуск» и рабочий стол остаются системными,
а Проводник всегда доступен.

## Возможности

**Файлы и папки**
- вкладки, адресная строка с «хлебными крошками», поиск по папке, таблица и плитки;
- панель сведений с предпросмотром изображений, текста и PDF;
- копирование, перемещение, переименование, перетаскивание и Корзина через системный движок Windows;
- отмена последних действий (Ctrl+Z): переименование, создание, копирование, перемещение, удаление в Корзину;
- контекстное меню в стиле Windows 11 и классическое меню со всеми пунктами программ (Shift+правый щелчок);
- «Этот компьютер», Корзина с восстановлением, «Сеть» с компьютерами и общими папками.

**Главная** — быстрый доступ, недавние и избранное, накопители, «Продолжить играть» и сводка AI.

**Игры** — библиотека Steam, Epic Games, Xbox / Game Pass, GOG и своих папок с портативными версиями:
обложки, последний запуск, запуск в один щелчок, скрытие ненужного.

**Приложения** — все приложения из меню «Пуск», включая приложения из Store.

**AI-центр**
- локальные модели Ollama и LM Studio, скиллы Claude Code и Codex, MCP-серверы AI-клиентов (секреты скрыты), проекты с агентами;
- «Найдено в ваших папках»: скачанные скиллы, модели, MCP-конфиги и промпты, где бы они ни лежали, —
  скилл можно установить для Claude Code одной кнопкой.

**Торренты** — загрузки BitTorrent, µTorrent, qBittorrent, Transmission и Deluge с прогрессом и торрент-файлы
в ваших папках; уже добавленные в клиент файлы распознаются по info hash и их можно убрать.

**Разбор «Загрузок»** — подсказывает, что можно удалить (установщики уже установленных программ,
распакованные архивы, точные копии, добавленные торренты), и раскладывает остальное по папкам. Ничего не
происходит без нажатия, и всё отменяется.

**Настройки** — тема, материал окна (обычный, Mica по всему окну или прозрачное стекло с регулировкой),
вкладки прошлого сеанса при запуске, разделы боковой панели и главной, сортировка, подтверждение удаления,
классическое меню, папки игр и AI-поиска.

**Открывать папки в Nexus** — по желанию папки, диски и Win+E открываются в Nexus вместо Проводника.
Настройка касается только вашей учётной записи и выключается тем же переключателем.

## Сборка и запуск

Нужны Windows 10 версии 2004 или новее (лучше Windows 11) и [.NET 10 SDK](https://dotnet.microsoft.com/download/dotnet/10.0).

```powershell
# сборка, тесты и запуск
powershell -ExecutionPolicy Bypass -File tools/build.ps1 -Test -Run

# открыть сразу нужный раздел
powershell -ExecutionPolicy Bypass -File tools/build.ps1 -Run -RunArgs "--page=games"
```

Приложение собирается как самодостаточное (unpackaged, self-contained): Windows App SDK ставить отдельно не нужно.

## Устройство

| Папка | Что внутри |
| --- | --- |
| `src/Nexus.Core` | логика без интерфейса: файловые операции и интеграция с оболочкой Windows, игры, приложения, AI, торренты, разбор загрузок, настройки |
| `src/Nexus.App` | интерфейс на WinUI 3: окно, страницы, модели представления, стили |
| `tests/Nexus.Core.Tests` | тесты xUnit v3 (Microsoft.Testing.Platform); работают только во временных папках |
| `tools` | скрипт сборки для разработки |

## Безопасность

- удаление по умолчанию идёт в Корзину и отменяется; безвозвратное удаление Windows подтверждает сама;
- Nexus не меняет системную оболочку (Winlogon) и ничего не пишет в систему без вашего действия;
- MCP-конфиги показываются без токенов и ключей.
