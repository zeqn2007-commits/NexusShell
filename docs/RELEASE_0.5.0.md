# Nexus Shell 0.5.0

## Библиотека игр

- Nexus обнаруживает Steam, Epic Games, Xbox и локальные установки.
- Файлы `.torrent` читаются напрямую: источник или торрент-клиент значения не имеет.
- Торрент связывается с игрой только после обнаружения реальной папки и подходящего `.exe`.
- Карточки показывают обложку Steam, локальную картинку или системную иконку запускаемого файла.
- У каждой игры есть запуск, просмотр файлов в Nexus, скрытие из библиотеки и восстановление скрытых игр.
- Локальную игру можно отправить в Корзину после точного подтверждения.
- Для игр лаунчеров удаление перенаправляет в штатное управление приложениями Windows.

## Иконки и приложения

- Добавлен раздел «Приложения» с ярлыками из меню «Пуск».
- Значки извлекаются из Windows Shell и сохраняются в локальный кэш.
- Приложения открываются плитками с настоящими иконками, а не именами файлов.
- Файлы и папки используют системные значки, изображения — реальные миниатюры.
- Подготовка большой библиотеки иконок выполняется параллельно.

## Торренты

- Добавлен отдельный раздел «Торренты».
- Nexus ищет `.torrent` в Загрузках, на рабочем столе и в добавленных игровых каталогах.
- Метаданные читаются локально; сетевой сервис или привязка к конкретному клиенту не нужны.

## Проверено

- Release-сборка: 0 ошибок, 0 предупреждений.
- Тесты обнаружения Steam, Epic Games, локальной и связанной с торрентом игры.
- Тесты скрытия и восстановления игр.
- Визуальная проверка реальных иконок приложений и обложек игр.
