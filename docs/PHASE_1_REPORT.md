# Отчёт первой рабочей версии

## Реализовано

- самодостаточный Windows App SDK runtime — отдельное окно установки не появляется;
- нативное окно WinUI 3 в стиле согласованного референса;
- вкладки верхнего уровня и активное пространство «Проекты»;
- боковая навигация: Главная, Последние, Избранное, Входящие, пространства и AI-центр;
- реальные пользовательские папки и диски;
- асинхронное чтение, поиск, список и плитки;
- мультивыбор, создание папок, переименование, копирование, вырезание и вставка;
- удаление через Корзину Windows после подтверждения;
- стандартные горячие клавиши файлового менеджера;
- закрываемая рабочая вкладка «Файлы»;
- открытие файлов системным приложением;
- панель свойств и предпросмотр изображений;
- реальные недавние файлы из Документов, Загрузок и Рабочего стола;
- обнаружение локальных Ollama-моделей, AI-проектов, Codex Skills и MCP-конфигураций;
- безопасные рекомендации для файлов в корне «Загрузок»;
- перемещение только после явного подтверждения;
- остановка при конфликте имён;
- отмена последнего подтверждённого перемещения;
- аварийная команда открытия стандартного Проводника.
- самодостаточный установщик Inno Setup для x64 без прав администратора.
- отдельная библиотека реальных установленных игр из манифестов Steam и Epic Games и папок Xbox;
- обнаружение локальных portable/repack-игр в стандартных и выбранных пользователем папках;
- запуск игры через лаунчер, открытие каталога установки и панель сведений;
- исключение Steamworks Redistributables и папок сохранений из списка игр;
- честные виртуальные разделы «Последние», «Избранное» и «Архив» без подмены содержимым других папок.

## Защита

Автоматическое перемещение выключено. Nexus не меняет системную оболочку, `explorer.exe`, Program Files, Windows и AppData. Установщик создаёт только стандартную запись деинсталляции текущего пользователя. Ручные файловые операции не перезаписывают существующие элементы, а удаление направляется в Корзину.

## Проверки

- Debug/Release сборка: 0 ошибок, 0 предупреждений;
- тесты перечисления и классификации файлов;
- тест подтверждённого перемещения в изолированном временном профиле;
- тест отмены перемещения;
- тесты создания, переименования, копирования и перемещения в изолированном временном каталоге;
- тесты обнаружения игр Steam/Epic, построения команд запуска и исключения системных компонентов;
- тесты, запрещающие возврат ложных папочных назначений для «Игр», «Последних», «Избранного» и «Архива»;
- Release-сборка установщика Inno Setup 6;
- визуальная проверка окна при системном DPI-масштабировании.

## Следующий этап

Очередь копирования и перемещения с подробным прогрессом и паузой, постоянный журнал операций, системное расширение контекстного меню Windows, сетевые ресурсы и отдельный экран приложений.
