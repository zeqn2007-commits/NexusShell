# План реализации Nexus Shell

> Это исходный поэтапный план, а не актуальный отчёт о готовности. Флажки ниже
> отражают ранний этап проекта и не заменяют regression tests или runtime QA.
> Текущее проверенное состояние и известные блокеры описаны в
> `docs/CLAUDE_HANDOFF.md`.

## Этап 1 — безопасный браузер файлов

- [x] нативное окно WinUI 3;
- [x] главная «Проекты» и пространства;
- [x] известные папки и диски;
- [x] асинхронное чтение каталогов;
- [x] поиск внутри открытой папки;
- [x] список и сетка;
- [x] панель свойств выбранного файла;
- [x] открытие файла системным приложением;
- [x] кнопка аварийного открытия в Проводнике;
- [x] локальное обнаружение Ollama-моделей, Codex Skills и MCP-конфигураций;
- [x] рекомендации для «Входящих» с подтверждением и отменой.

Критерий готовности: приложение собирается, запускается и не изменяет файлы без отдельного явного подтверждения пользователя.

## Этап 2 — надёжные файловые операции

- копирование и перемещение с очередью, прогрессом и отменой;
- переименование и создание папок;
- удаление только через Корзину;
- обработка конфликтов и прав доступа;
- журнал ручных операций.

Критерий готовности: операции проходят интеграционные тесты в изолированном временном каталоге и не блокируют UI.

## Этап 3 — Входящие и рекомендации

- наблюдение только за выбранными пользовательскими папками;
- классификация по расширению, имени и источнику;
- предложения без физического перемещения;
- редактор правил и оценка уверенности.

Критерий готовности: ни одно предложение не изменяет файл до явного подтверждения.

## Этап 4 — полуавтоматическая организация

- применение подтверждённых правил;
- журнал до/после;
- отмена перемещений;
- конфликты имён и заблокированные файлы;
- аварийное отключение автоматизации.

## Этап 5 — повседневная замена Проводнику

- вкладки и несколько окон;
- быстрый глобальный поиск;
- избранное и настоящая история недавнего;
- эскизы и расширенный предпросмотр;
- сетевые расположения и съёмные диски;
- контекстные команды.

## Этап 6 — установка и системная интеграция

- MSIX;
- автозапуск с согласия пользователя;
- «Открыть в Nexus»;
- обработка обновлений;
- аварийный запуск стандартного Проводника.

Полная замена системной оболочки не входит в основной продукт и рассматривается только как отдельный эксперимент после длительного тестирования.
