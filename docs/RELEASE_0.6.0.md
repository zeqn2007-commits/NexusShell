# Nexus Shell 0.6.0

## Интерфейс

- В верхней панели остаётся один рабочий таб с названием текущего раздела.
- «Приложения», «Торренты», «Последние» и «Избранное» получили собственные заголовки, описание и точный счётчик.
- Виртуальные коллекции используют компактную панель команд без неуместных действий создания и вставки.
- Длинные названия приложений ограничены двумя строками.

## Логика представлений

- «Приложения» открываются плитками с настоящими системными иконками.
- «Торренты» всегда открываются списком с датой, типом и размером, даже после перехода из плиточного режима.
- Имена и значки рабочего таба синхронизируются с текущей папкой, играми, приложениями и торрентами.

## Стабильность и скорость

- Источники локальных изображений преобразуются в корректные `file:///` URI для WinUI.
- Устранено падение при отрисовке большой библиотеки приложений.
- Во время загрузки скрывается промежуточное представление, а готовая сетка показывается одним переключением.
- Одинаковые системные иконки папок и типов файлов используют общий кэш.

## Проверено

- Release-сборка: 0 ошибок, 0 предупреждений.
- Все тесты Nexus.Core пройдены.
- Визуально проверены «Проекты», «Приложения», «Торренты» и «Игры».
- В библиотеке приложений стабильно отображаются 117 ярлыков, в игровой библиотеке — 12 игр.
