# Nexus Shell 0.8.0

Дата подготовки: 02.08.2026.

## Основные изменения

- исправлена стабильность иконок игр и приложений после повторного обновления;
- portable/repack-игры и `.torrent` распознаются независимо от клиента, а
  служебные программы вроде SimpleUnlocker больше не выдаются за игры;
- приложения с одинаковыми именами, но разными AppID, не склеиваются;
- системные компоненты скрываются отдельно, обычные Store-приложения остаются
  в основном списке;
- значительно расширено обнаружение Codex, Claude, Cursor, Ollama, LM Studio,
  Hugging Face, ComfyUI, Stable Diffusion и локальных AI-проектов;
- раздел MCP показывает конфигурации Codex, Claude, Cursor, VS Code и найденных
  AI-проектов;
- Настройки стали полноценной страницей с источниками игр и AI-проектов;
- исправлены переходы между Настройками, Корзиной и вкладками, восстановление
  поиска и коллизии физических папок с названиями виртуальных разделов;
- файловые операции получили измеримый прогресс, скорость, паузу, отмену и
  безопасное разрешение конфликтов имён;
- усилены cross-volume операции, сохранение метаданных и fail-closed проверки;
- усилена COM-реализация Корзины и добавлен отдельный безопасный smoke-тест;
- интерфейс адаптирован для широких экранов и более аккуратного списка файлов.

## Проверка

- `NexusShell.sln`, Release: 0 предупреждений, 0 ошибок;
- `Nexus.Core.Tests`: полный набор проверок проходит;
- тест нестабильности файловых операций: 12 последовательных успешных прогонов;
- `Nexus.RecycleBin.SmokeTests`: чтение и ABI probe проходят без изменения
  содержимого пользовательской Корзины.

## Артефакты

Ожидаемые файлы релиза:

- `NexusShell-Setup-0.8.0-x64.exe`;
- `NexusShell-Setup-0.8.0-x64.sha256`;
- `NexusShell-Setup-0.8.0-x64.manifest.json`;
- `NexusShell-Setup-0.8.0-x64.manifest.txt`.

Установщик собирается self-contained: отдельная установка .NET или Windows App
Runtime не требуется. Неподписанный локальный релиз явно помечается как
`UNSIGNED` в manifest.
