Copy the prompt below into Claude Code after opening the repository root.

```text
Изучи проект Nexus Shell перед любыми изменениями.

Обязательно прочитай полностью:
- CLAUDE.md
- docs/CLAUDE_HANDOFF.md

2. Запусти консольный harness Nexus.Core.Tests именно через dotnet run.

  через dotnet run;

  отдельно;
- установщик собирай только после зелёных Core tests и отдельного запроса.

После аудита остановись и дождись выбора задачи.
```
