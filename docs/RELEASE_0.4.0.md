# Nexus Shell 0.4.0

## Исправлено

- Раздел «Игры» больше не открывает папку сохранений и не показывает пустой `desktop.ini`.
- «Избранное» стало постоянной коллекцией и сохраняется в `%LocalAppData%\Nexus Shell\favorites.json`.
- «Архив» стал обычной физической папкой `Документы\Архив Nexus`.
- Необязательные AI-разделы показывают честное пустое состояние, а не содержимое посторонней папки.
- MCP показывает файл конфигурации, а не весь служебный каталог Codex.
- `desktop.ini`, `Thumbs.db` и скрытые системные элементы больше не засоряют обычные списки.
- Раздел «Медиа» показывает только изображения, видео и аудио.
- Исправлена адресная строка: можно вставить путь и перейти по `Ctrl+L`.
- Исправлена синхронизация активного пункта боковой панели после переходов назад, вперёд и вверх.
- Ошибки файловых операций теперь видны на всех экранах.
- Перемещение между разными дисками выполняется через безопасное копирование с последующим удалением источника.
- Системные папки определяются через Windows Known Folders и корректно работают с OneDrive.
- Журналы запуска перенесены из каталога приложения в `%LocalAppData%\Nexus Shell\Logs` и ограничены по размеру.

## Добавлено

- Сортировка по имени, дате, типу и размеру с обратным порядком.
- Переключение списка и плиток в файловом режиме.
- Системный буфер обмена: копирование между Nexus и Проводником.
- Копирование файлов перетаскиванием из других Windows-приложений.
- Контекстное меню: открыть, вырезать, копировать, вставить, переименовать, избранное, путь, удалить, свойства.
- Рабочий стол, Изображения, Видео и Музыка в боковой навигации.
- Автоматическое обнаружение локальных игр в папках `Games`, `Игры`, `Portable Games` и добавленных пользователем каталогах.
- Прямой запуск локальных portable/repack-игр через найденный основной `.exe`.
- Фильтры установщиков, деинсталляторов, redistributable, updater и crash-report компонентов.
- Необязательный автозапуск при установке.

## Проверено

- Release-сборка: 0 ошибок, 0 предупреждений.
- Изолированные тесты файловых операций, избранного, организации, Steam/Epic и локальных игр.
- Реальные экраны главной, библиотеки игр, архива и пользовательских документов.
- Самодостаточный запуск без отдельной установки Windows App Runtime или .NET.

## Осознанно не включено

- Nexus не заменяет `explorer.exe` и не изменяет Winlogon Shell.
- Фоновая автоматическая сортировка не включается без отдельной настройки.
- Большие операции пока не имеют очереди с паузой и подробным графиком скорости.
- Установщик не подписан цифровой подписью.
