# Правила безопасности Nexus

1. Nexus не изменяет `explorer.exe`, Winlogon Shell и системную оболочку без отдельного будущего запроса и отдельного экспериментального режима. Установщик создаёт только стандартную запись деинсталляции текущего пользователя.
2. Каталоги Windows, Program Files, ProgramData и AppData никогда не участвуют в автоматической сортировке.
3. Установленные приложения и игры не перемещаются.
4. Автоматическое удаление запрещено. Ручное удаление выполняется только через Корзину и после подтверждения.
5. Каждая будущая автоматическая операция должна иметь журнал, понятное объяснение и команду отмены.
6. При конфликте имён операция останавливается и просит пользователя выбрать действие.
7. Открытые или заблокированные файлы не перемещаются.
8. Полуавтоматический режим является режимом по умолчанию; сомнительные файлы остаются во «Входящих».
9. Тесты не выполняют операции над пользовательскими папками. Для интеграционных тестов создаётся отдельный временный каталог.
10. Стандартный Проводник всегда доступен как аварийный резерв.
11. Копирование, перемещение и переименование останавливаются при конфликте имён; существующие данные не перезаписываются.
