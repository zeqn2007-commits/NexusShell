# Nexus Shell Design

## Theme

Тёмная тема для длительной работы вечером и при приглушённом освещении. Визуальный образ — «тихий рабочий стол перед началом дня»: почти чёрный экран, матовый графит системных панелей и один ясный кобальтовый сигнал в активном пути.

Цветовая стратегия — restrained: нейтральные поверхности занимают почти весь экран, акцент используется только для текущего выбора, фокуса и основного действия.

## Canonical color palette

Канонические значения хранятся в OKLCH; WinUI получает эквивалентные sRGB-значения в `App.xaml`, поскольку XAML не поддерживает OKLCH напрямую.

- Canvas: `oklch(0.12 0 0)`
- Chrome: `oklch(0.16 0.006 258)`
- Raised surface: `oklch(0.20 0.008 258)`
- Inset surface: `oklch(0.09 0 0)`
- Primary text: `oklch(0.96 0.006 258)`
- Secondary text: `oklch(0.78 0.012 258)`
- Tertiary text: `oklch(0.64 0.014 258)`
- Nexus violet: `oklch(0.65 0.18 286)`
- Selected surface: `oklch(0.27 0.075 286)`

Семантические warning, error и success появляются только в соответствующих состояниях и не входят в декоративную палитру.

## Typography

Одна системная гарнитура: Segoe UI Variable Text. Фиксированная продуктовая шкала:

- Page title: 28 px / 600
- Section title: 20 px / 600
- Control and row title: 14 px / 500–600
- Body: 14 px / 400
- Metadata: 12 px / 400

Иерархия строится прежде всего весом, цветом и пространством. Названия файлов не обрезаются без доступной подсказки с полным текстом.

## Layout

- Базовый шаг: 4 px.
- Боковая навигация: 228 px.
- Панель команд: 64 px.
- Строка файла: 52 px.
- Панель предпросмотра: 320 px, появляется только после выбора.
- Минимальная ширина основного окна: 960 px.
- Связанные элементы разделяются на 8–12 px; самостоятельные группы — на 24–32 px.

Главная страница более воздушная. Рабочий список файлов плотнее и использует знакомые колонки. На узком окне панель предпросмотра закрывается первой, затем сворачивается боковая навигация.

## Depth and surfaces

Глубина строится сменой матовых поверхностей и тонкими полупрозрачными границами. Декоративные тени и постоянное размытие не используются. Скругления:

- кнопки и поля: 8 px;
- панели и карточки пространств: 12 px;
- диалоги: 14 px.

## Signature

Пространства — уровень выше обычных папок. Основной экран «Проекты» следует композиции `design/nexus-reference.png`: вкладки сверху, пространства и AI-центр в основном полотне, реальные недавние файлы снизу и контекстная панель справа.

Кнопка `+` открывает отдельную вкладку «Файлы» по референсу `design/nexus-reference-compact.png`. Она не заменяет основной экран: внутри остаются четыре пространства, плотная таблица недавних файлов и крупная обложка выбранного документа справа. В боковой панели добавлена группа «Хранилища», а AI-центр сохранён ниже в той же прокрутке.

## Interaction

- Навигация и частые действия реагируют без декоративной анимации.
- Появление панели предпросмотра — короткое системное состояние, не спектакль.
- Каждая кнопка имеет hover, pressed, focus и disabled состояния.
- Двойной щелчок по папке открывает её; по файлу — системное приложение по умолчанию.
- Раздел «Игры» строится вокруг установленной игры: название и источник первичны, путь вторичен, запуск — главное действие. Steam, Epic Games, Xbox и локальные portable/repack-установки объединяются в одну библиотеку. Папки сохранений, установщики и компоненты лаунчера не считаются играми.
- Пустой виртуальный раздел объясняет, какие источники были проверены, и никогда не подменяется несвязанной физической папкой.
- Обычные файловые операции выполняются только по прямой команде пользователя; удаление идёт через Корзину, а автоматическая сортировка остаётся отдельным подтверждаемым действием.
